
# Humanus – Career Management Platform

🏆 1st Place – Health Tech Hackathon: Conecta Saúde (August 2025)

Humanus is a career management platform designed to support nurses and nursing technicians in their professional growth. The solution was built in just three nights during the Health Tech Hackathon: Conecta Saúde, addressing the lack of structured career planning in healthcare.## Features

- Dashboard with key stats, quick actions and mood tracker
- Feedback (received and given)
- Training & Microlearning modules
- Career Plan with milestones, OKRs and 1:1 scheduling
- Rewards Store with gamification

## Tech Stack

**Frontend**: Next.js, React, TypeScript, Tailwind CSS, shadcn/ui
**Backend** (mocked): Node.js + REST API
**Design**: Figma
